# Hondrovix MX — responsive HTML landing

A hand-coded responsive reconstruction of the approved visual layout. All blocks are separate HTML/CSS elements, all pictures are standalone image assets cropped from the supplied approved visual or taken from the user's original product images. The screenshot is not embedded as a full-page image.

Open `index.html` or upload contents to a static host. Design covers mobile screen sizes 320–640px, tablet 641–950px and desktop to 1180px; forms are **demo-only** until connected to a licensed order-processing endpoint.

Original photos on file: product packaging from `4.png`, real product scenes from `1.jpg` and `3.jpg`. Remaining small artwork is derived from the approved design image; portraits and testimonials are illustrative, as disclosed in the added footer. No tracking or Keitaro configurations included.

To run locally: `python3 -m http.server 8080` from this folder.
